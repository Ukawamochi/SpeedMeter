### 4.3 exp002 は6エポック時点で収束しているか

**収束していない。** 根拠:

1. 検証MAE・検証損失はエポック4・5・6と連続して改善しており、エポック5→6 の改善幅（MAE −0.0309、損失 −2.04）は exp001 の同区間（−0.0196、−0.80）より大きい。改善幅の縮小も exp001 より緩い
2. 最良エポック＝最終エポック（6）で、検証損失の反転は起きていない。エポック3で検証損失が 24.65 → 36.75 と一度跳ねたが、エポック4で回復している
3. 学習損失はエポック5→6 でも 13.4% 下がっており、学習データ（拡張あり）への当てはまり自体がまだ進んでいる
4. 拡張ありの学習データに対する学習MAE（0.6290）が、拡張なしの検証MAE（0.5992）より大きい。過学習の兆候（検証の悪化・学習との差の拡大）は見られない

したがって**延長によって exp002 の検証MAEが改善する余地はある**。ただし何エポックでどこまで下がるかは、この6点の曲線からは言えない。
仮に直近の改善幅（−0.03 / エポック）が縮みながら続いたとしても、exp001 の 6エポック時点の 0.5013 に届くかどうかは外挿の仮定次第で、本資料では結論できない。
また exp001 も同じく収束していない（`docs/experiments/003-first-model.md` 0節・3節。エポック5→6 で −0.0196）ので、延長して比べる場合は両方を延長しないと同じ条件の比較にならない。

### 4.4 exp002 の方が悪い理由：学習の遅れか、拡張と dev の分布の不一致か

2つの可能性を手元の数値で区別できる範囲で整理する。

**(1) 同じエポック数では拡張ありの方が学習が進みにくい（遅れ）を支持する事実**

- 4.3節のとおり exp002 は収束しておらず、学習データ（拡張あり）にすら exp001 ほど当てはまっていない（学習MAE 0.6290 vs 0.4052）
- exp002 のエポック6（検証MAE 0.5992）は exp001 のエポック3（0.6092）とエポック4（0.5497）の間に位置し、曲線の形は「exp001 を遅らせたもの」に近い
- 回帰の傾き（予測 = a × 正解 + b の a。再集計）は exp001 0.8248、exp002 0.7588 で、exp002 の方が平均への縮みが強い。平均への縮みは学習が浅いモデルに典型的な形である（ただし exp001 の途中エポックの予測は保存されておらず、同じ検証MAEの時点での傾きは比べられない）

**(2) 拡張そのものが dev の分布に合わない（不一致）を示唆する事実**

- 検証MAE がほぼ同じ exp001 エポック3（0.6092）と exp002 エポック6（0.5992）で帯別を比べると、一様に遅れているのではなく形が違う:

  | 帯 | exp001 エポック3 | exp002 エポック6 |
  | --- | ---: | ---: |
  | 4未満 | **0.4556** | 0.5180 |
  | 4以上6未満 | 0.4907 | 0.4917 |
  | 6以上8未満 | 0.6894 | **0.6200** |
  | 8以上 | 1.7358 | **1.5145** |
  | 相関 | **0.8734** | 0.8663 |

  exp002 は速い帯で良く、4未満の帯で悪い。ただし exp001 の 4未満の帯はエポック間で 0.4556 → 0.5115 → 0.4410 と ±0.06 程度揺れており、この差がこの揺れを超える差かどうかは6点からは断定できない
- 4未満の帯の偏り（予測 − 正解の平均、再集計）は exp001 +0.1138 → exp002 +0.2925 と、過大評価が約2.6倍になった（他の帯: 4以上6未満 −0.0701 → −0.0374、6以上8未満 −0.3008 → −0.4200、8以上 −1.2851 → −1.4603）
- これと整合する形で、無音窓への出力（D2 デジタル無音 0.08 → 1.44 モーラ、D3 の P(無音0.2秒) 0.0001 → 0.92 モーラ）が増えている。
  拡張ありのモデルは「無音・低エネルギーの区間にも出力を出す」方向に振る舞いが変わっており、これは学習の遅れだけでは説明しにくい質的な変化である。
  4未満の帯（ゆっくり・間の多い発話）の過大評価の増加はこの変化と同じ向きである。ただし拡張のどの要素（雑音重畳・音量変化・残響・帯域制限・時間伸縮・周波数マスク）がこの変化を生んだかは、全要素を同時に有効にした1条件しかないため区別できない
- クリップ長別の MAE（再集計）: 2.0秒未満 0.8783 → 0.9838、2〜4秒 0.5171 → 0.6038、4秒以上 0.4380 → 0.5470。
  偏りは 2.0秒未満で −0.3879 → −0.0937、2〜4秒で −0.1499 → −0.0265 と小さくなり、4秒以上で −0.1098 → −0.2097 と大きくなった。
  長さによって誤差の向きの変わり方が異なり、これも一様な遅れとは異なる形である

**区別できないこと**

- 6エポックの時点では両方の要因が同時に存在しうる。exp002 を延長したときに (a) 全帯が同じように改善して exp001 に追いつくのか、(b) 4未満の帯の過大評価や無音窓への出力が残ったまま頭打ちになるのかは、延長した学習曲線と延長後の D2・帯別偏りがなければ判別できない
- exp001 の途中エポックのチェックポイント・予測は保存されていないため、「同じ検証MAEの時点での D2・D3・偏り」の比較はできない
- どの拡張要素が効いているか（個別の寄与）は、要素ごとに外した条件がないため区別できない
- 以上の数値はすべて dev（Common Voice）に対するもので、dev に雑音・残響の強い録音がどれだけ含まれるかは測っていない。拡張が想定する劣化条件が dev にほとんど無い場合、dev の指標だけでは拡張の利点が現れにくいが、その割合は本資料からは分からない

## 5. 所見のまとめ（事実）

1. 6エポック・同一設定では、拡張ありの exp002 は拡張なしの exp001 より dev の全指標で悪い（MAE 0.5013 → 0.5992、+19.5%。4つの帯すべて悪化、相関 0.8905 → 0.8663）。処理時間（同日測定で 4.1766 vs 4.1898 ms）とモデルサイズ（2,005,357 バイト）は同じ
2. 低出力事例は dev 全件で 215 → 148 件に減ったが、exp001 の誤差上位の63件のうち50件は exp002 でも 1.0 未満のままである
3. D2 の MUSAN noise 窓への出力は 4.70 → 1.74 モーラに下がった一方、デジタル無音窓への出力は 0.08 → 1.44 モーラに上がり、D1 は 0.436 → 0.767、D3 は 0.057 → 0.244 に悪化した。exp001 の D1・D2 は拡張なしの条件の値である。B1〜B5 の閾値に照らすと exp002 は B1・B2（無音・noise の両方）の閾値を超え、D3 は閾値 0.25 の直下にある。**方式Bへの移行の判定は人間の指示により保留**
4. exp002 は6エポック時点で収束していない（検証MAE・検証損失とも連続改善、改善幅は exp001 より大きい、過学習の兆候なし）。延長の余地はあるが、どこまで改善するかは本資料からは言えない。exp001 も収束していない
5. exp002 の1エポックは約36.7分（exp001 の約1.6倍）。0からの学習で 12エポックは約7.3時間（6.0〜8.3）、20エポックは約12.2時間（10.0〜13.8）と見積もられる
6. exp002 が悪い理由として「学習の遅れ」を支持する事実（未収束、学習データへの当てはまりも浅い、平均への縮みが強い）と、「拡張と dev の不一致／振る舞いの質的変化」を示唆する事実（同程度の検証MAE の時点で帯別の形が異なる、4未満の帯の過大評価と無音窓への出力の増加）の両方がある。どちらが主因かは、6エポックの結果だけでは区別できない
