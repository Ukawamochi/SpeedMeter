### 2.3 移行を支持する窓単位の根拠（B1 の裏付け）

- 窓単位の MAE（0.8314）から偏り（−0.5761）を除いた値は 0.7159、帯別に偏りを除くと 4未満 0.529・4以上6未満 0.580・6以上8未満 0.615・8以上 0.827（再集計）。これは**出力の系統的な過小を直せば、窓単位の誤差がかなり下がる余地がある**ことを示す。ただし帯は正解で決まるので、帯別の偏りの除去は正解を知ったうえでの分解であり、実現できる値ではない
- 単一クリップの窓の偏り（−0.682）は連続発話（−0.512）より大きい（window_eval.md 4.1節）。単一クリップの窓の多くは発話の途中で切られる位置にある（dev_window_build.md 2.2節）ので、端で切られた発話の過小という 005 2.3節の見立てと向きが合う（推測。窓の端で切られるモーラの数ごとの偏りは集計していない）
- 方式Bが直すのは窓の端での過小（学習と推論の条件差）である。8以上の帯の平均への回帰は方式Bでは直らない可能性がある。移行の判定はこの点に依存しない（B1 は D1 の値で決まる）が、7-2 で方式Bの効果を読むときは帯別の偏りを分けて見る必要がある

### 2.4 条件の見直しについての提案（人間への提案。条件は変えていない）

B1 に該当したので「どの条件にも該当しないが窓単位の結果が移行を支持する」場合には当たらない。次の2点は条件の運用についての提案として分けて書く。

1. **B1〜B5 はすべて clean の値である。** 雑音下の窓単位の偏り（−1.1 前後）はクリップ単位（−0.07）と大きく違い、原因が確かめられていない（1.1節）。方式Bの効果を 7-2 で判定するとき、D1 を雑音下（dev_noisy と同じ SNR 3条件）でも測ることを検討されたい
2. **B2 は D2（人工の無音・雑音の窓）で判定するが、実際の音声の正解0の窓の出力はそれより大きい**（単一クリップの正解0の窓で平均 1.208 モーラ、4.2節）。窓単位の正解が使えるようになったので、B2 の対象に dev_window の正解0の窓を加えるかを検討されたい。ただし単一クリップの正解0の窓はアライメントの位置の誤りを含みうる（6節）ので、閾値の置き方には別の検討が要る

## 3. 窓単位の目標値の案

### 3.1 002 の決め方をどう当てはめたか

002 3.3節の目標値は次の4つの考え方で引かれている。窓単位ではそのまま使えないものがあるので、置き換えを明記する。

| 002 の考え方 | 窓単位での扱い |
| --- | --- |
| (c) 包絡法と書き起こしの差を、どの帯でも6割以上詰める | 書き起こしベースラインの窓単位の値が無い。代わりに、002 の目標値がクリップ単位の包絡法の値の 0.53〜0.61倍（dev の部分集合）であったことに合わせ、**窓単位の包絡法の値（clean・主指標）の 0.6倍以下**を上限とする（条件 C） |
| (d) 表示値としての相対誤差（中央の2帯 8%、端の2帯 15%） | 4未満の帯は窓単位では正解0の窓（51,364窓）を含み、帯の平均の正解が 1.716 と小さいので、相対誤差の基準が意味を持たない。中央の2帯と8以上は参考として相対誤差を併記する |
