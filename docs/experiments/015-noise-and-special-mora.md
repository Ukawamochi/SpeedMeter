## 2. exp019: 強く縮めた窓に雑音を重ねない

### 2.1 学習の窓に雑音を重ねた割合

| 項目 | exp016 | exp019 |

exp016 の「50%」は、雑音の抽選が確率 0.5 の独立な抽選であることからの設計値である。同じ規則・同じ窓の抽選の exp020 の実測 50.02% は代わりの参考であって、exp016 の実測ではない。伸縮率 0.7 未満の窓は、毎秒10以上の窓の約59%、12以上の約82%を占める（decisions/012 の見込み）。

### 2.2 雑音下の過大は減ったか

| 指標（雑音下） | exp005 | exp016 | exp019 | exp019 − exp016 |
| --- | ---: | ---: | ---: | ---: |
| 雑音下まとめ MAE | 0.7001 | 0.7490 | 0.7226 | −0.0264 |
| 雑音下まとめの偏り | −0.0154 | +0.0509 | +0.0057 | −0.0452 |
| 偏り 4未満 | +0.2109 | +0.2721 | +0.2898 | +0.0178 |
| 偏り 4〜6 | +0.2793 | +0.3042 | +0.3037 | −0.0005 |
| 偏り 6〜8 | +0.1388 | +0.1826 | +0.1325 | −0.0501 |
| 偏り 8以上 | −0.5970 | −0.4749 | −0.6111 | −0.1362 |
| SNR 5dB MAE | 0.7536 | 0.8103 | 0.7693 | −0.0410 |

- 全体の偏りと MAE は縮み、MAE の差（−0.0264）は 011 の s（0.005）の約5倍である。仮説の予測（強く縮めた窓の雑音をやめれば雑音下の過大が減る）の向きとは合う
- 帯ごとに見ると、過大が元（exp005 並み）に戻ったのは 6〜8 だけ（+0.1826 → +0.1325）。4〜6 は変わらず、4未満はむしろ悪化した。全体の偏りの縮みには、8以上の過小の拡大（−0.4749 → −0.6111）も効いている。つまり**過大が全体に減ったというより、速い側の帯の出力が下がって平均が動いた面がある**（観察。内訳の切り分けは窓の重みづけが要るので行っていない）
- 013 5.3節の仮説は、強く縮めた窓は速い窓に集中する（毎秒10以上の約6割）ので、速い帯（6〜8 以上）で効くはずという形で検証できる。6〜8 の結果は仮説と整合する。4未満・4〜6 の雑音下の過大は伸縮率 0.7 未満の窓とは別の要因（雑音下の遅い窓の出力の高さ）による可能性が高い（推測）
- 雑音を重ねた窓が約50% → 約42%に減った効果と、強く縮めた窓の雑音をやめた効果は、この1回の学習では分けられない

### 2.3 副作用

- 追従: x2 の天井 13.417 → 12.832（−0.585、揺れ 0.069 の約8倍）、x1.5 の天井 −0.287。強く縮めた窓（＝速い窓）が雑音なしになり、雑音の有無と速さに相関が付いた影響の疑い（decisions/012 の6節1・2、推測）。clean の偏りも −0.0384 → −0.0670、clean 8以上の偏りは −0.3642 → −0.4044 と過小側に動いた
- **正解0の窓の雑音下まとめ 0.5122 → 0.5631（+0.0509）**: 雑音下の過大は減ったのに、雑音だけの窓への出力は上がった。揺れ（0.072）より小さい差で、この1回では有意な悪化かは決められない。ただし D2（MUSAN noise 平均）も 0.5064 → 0.5686、SNR 5dB も 0.5712 → 0.6236 と同じ向きにそろっている。原因は不明（雑音を重ねた窓が減り、雑音への「0」の学習例が相対的に減った可能性など、推測）。基準（0.5）との差は +0.0631 で、揺れの範囲に収まる大きさだが、満たさないことに変わりはない
- 雑音下まとめ MAE は基準 0.72 に対し +0.0026 まで近づいた（4条件で最小の超過）

## 4. 最終モデルの候補（人間の指示: 基準に最も近いものを挙げる）

### 4.1 前提

指示書の目標は倍速音声への追従（評価2）で、2節の基準でも追従が「主」である。基準をすべて満たす条件は無いので、「基準に最も近い」ものを候補に挙げる。「最も近い」の測り方は一通りに決まらないので、複数の測り方を並べる。

### 4.2 測り方ごとの順位

| 測り方 | exp005 | exp016 | exp019 | exp020 |
| --- | ---: | ---: | ---: | ---: |
| (a) 満たさない項目の数（4項目） | **1** | 2 | 3 | 3 |
| (b) 超過の大きさ: 超過 ÷ 基準値の和（追従は 1.059/13.0 などと計算） | 8.2% | **6.5%**（C 4.0% + D 2.4%） | 14.3%（A 1.3% + C 0.4% + D 12.6%） | 33.9%（B 0.6% + C 3.4% + D 30.0%） |
| (c) 超過の最大の項目の大きさ（同上） | 8.2% | **4.0%** | 12.6% | 30.0% |
| (d) 超過 ÷ 揺れの目安の和（A 0.069、B 0.0031、C 0.005、D雑音下 0.072） | 15.3 | 6.0 | **3.8** | 7.9 |
| (e) 追従の目標（x2 の天井）の高さ | 11.941 | **13.417** | 12.832 | 13.081 |
| (f) x2 の MAE（低いほど良い） | 2.854 | **2.040** | 2.352 | 2.216 |

- 順位: (a) exp005 > exp016 > exp019 = exp020、(b)(c) exp016 > exp005 > exp019 > exp020、(d) exp019 > exp016 > exp020 > exp005、(e)(f) exp016 > exp020 > exp019 > exp005
- (d) の注: C の揺れに 0.005（011 の s）を使った。exp005 と exp007 の差 0.0006 を使うと exp016 は約29、exp019 は約2.6、exp020 は約25 で、exp019 の優位はさらに大きくなる。逆に D 雑音下の揺れ 0.072 は大きく、exp019 の D（+0.0631）も exp020 の D（+0.1498）も「揺れの範囲か 2倍程度」になる。揺れの目安は1回の観測で、不確かさが大きい
- (a)(b)(c) では exp005 が上位に入る。ただし exp005 は目標の追従を満たさない（x2 の天井 11.941、x2 の偏り −2.786）。目標が追従である以上、(a) の1項目は「主」の項目で、他の項目（副）の超過とは重みが違う。exp005 を候補にすると目標の用途で改善が無い（これは現在の基準構成そのものである）

### 4.3 候補: exp016

**候補は exp016（`configs/exp016.yaml`）とする**（根拠つきの推奨で、断定ではない）。

- 追従が目標である。x2 の天井・MAE・偏りのすべてで4条件の最良（13.417、2.040、−1.860）。基準 13.0 に +0.417 の余裕があり、揺れ 0.069 の約6倍
- 満たさない項目は雑音下まとめ MAE（+0.0290）と正解0の窓の雑音下まとめ（+0.0122）。後者は揺れ（0.072）より小さく、同じ設定の学習し直しで満否が変わりうる。前者は揺れ（s 0.005）の約5.8倍で、**埋まらない不足である**
- 項目数と超過の割合の測り方（a）（b）（c）では、exp016 が exp019・exp020 より上位、(b)(c) では exp005 より上位
- exp019 は雑音下まとめ MAE を基準の近くまで下げた（0.7226）が、追従を基準の下に落とし（12.832）、正解0の窓の雑音下まとめも悪化した。追従を主とする目標からは、追従を保った exp016 のほうが目標に近い。(d) の測り方（揺れの大きさで測った超過の和）だけは exp019 が上位で、雑音下の頑健さを追従の天井より優先する立場なら exp019 を選ぶ根拠になる。この選択は人間の判断に委ねる
- 種が1つなので、exp016 と exp019 の差の一部は揺れかもしれない。exp005 と exp007 の差は x2 の天井で 0.069、正解0の窓の雑音下まとめで 0.072 あるので、exp016 と exp020 の追従の差 0.336 は揺れより大きく、exp016 と exp019 の差 0.585 も同じく揺れより大きい。順位が入れ替わりうるのは正解0の窓の雑音下まとめと clean MAE の差
- 候補は基準をすべて満たす条件ではない。推論時間も測っていない（空欄）。採用の判断（A-4）は MPS が使えるようになってから（指示書 2026-09-30 0節5）
