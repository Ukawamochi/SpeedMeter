# 開発計画

各段階は1セッションにつき1段階のみを扱う。先の段階には進まない。

## 第1段階 環境構築と文書作成（このタスク）
- 担当: 環境構築
- 成果物: uvプロジェクト一式、scripts/check_env.py、docs/配下の文書、git初回コミット
- 完了条件: uv syncで環境が再現し、check_env.pyがMPS利用可能・Conv2d順伝播成功・pyopenjtalk読み変換成功を報告する

## 第2段階 ラベル生成の実装と検証
- 担当: ラベル生成
- 成果物: src/spkrate/labels/配下のモーラ数カウント実装、tests/配下の単体テスト
- 完了条件: テキストからpyopenjtalkでカタカナ読みを得て仕様の規則でモーラ数を数える実装が動作し、拗音・促音・撥音・長音・数字・英字・記号を含む単体テストが30件以上通過する

## 第3段階 評価セットの作成
- 担当: 評価データ整備
- 成果物: 実環境録音の正解ラベル、configs/splits/配下の話者単位分割ファイル
- 完了条件: 実環境の録音とその正解ラベルが固定され、公開コーパスのテスト分割が話者単位でconfigs/splits/に固定されている

## 第4段階 ベースラインの実装と測定
- 担当: ベースライン実装
- 成果物: src/spkrate/baselines/配下の信号処理ベースラインと書き起こしベースライン、測定結果
- 完了条件: 音量包絡から音節ピークを数える方法と書き起こしモデルを用いる方法の両方が実装され、評価指標が測定されている

## 第5段階 特徴量とデータ整備
- 担当: 特徴量パイプライン実装
- 成果物: src/spkrate/features/配下のメルスペクトログラム事前計算・保存処理、データ拡張実装、外れ値除外処理
- 完了条件: メルスペクトログラムが事前計算・保存され、データ拡張が実装され、区間長あたりのモーラ数が極端な事例が除外されている

## 第6段階 モデルと学習の実装
- 担当: モデル・学習実装
- 成果物: src/spkrate/models/、src/spkrate/train/配下の実装、MPSでの学習ログ
- 完了条件: MPS上でモデルの学習が実行できる

## 第7段階 誤り分析
- 担当: 誤り分析
- 成果物: 誤差上位区間の音声切り出しと一覧（聴取と分類は人間が行う）
- 完了条件: 誤差上位の区間が音声として切り出され一覧化されている

## 第8段階 条件の探索
- 担当: ハイパーパラメータ探索
- 成果物: 窓長、メル次元数、層数とチャネル数、膨張率、損失関数、拡張の有無を比較した結果
- 完了条件: 各条件について検証セットでの評価指標が比較されている

## 第9段階 ONNX書き出しと量子化
- 担当: モデルエクスポート
- 成果物: src/spkrate/export/配下のONNX書き出し・量子化実装、PyTorchとONNXの出力一致テスト、特徴量計算の参照値
- 完了条件: ONNX形式・int8動的量子化での書き出しが完了し、PyTorchとONNXの出力一致テストが通過し、特徴量計算の参照値が保存されている

## 第10段階 テストセットでの最終評価
- 担当: 最終評価
- 成果物: results/metrics.csvへの記録
- 完了条件: configs/splits/test.jsonに固定されたテストセットでの評価がresults/metrics.csvに記録されている
