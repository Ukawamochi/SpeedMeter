# 聴取用フォルダ

各フォルダの音声を番号順に連続して聴き、同じ番号の行に判定を書く。報告書は3つあり、このフォルダの「1_誤り事例_報告書.md」「2_アライメント_報告書.md」「3_無発話疑い_報告書.md」から開ける（resultsの中の本体へのリンクである）。

各音声の前に0.5秒、後に1秒の無音を入れてあるので、連続再生しても切れ目が分かる。どの音声も、ピークが−6dBFSになるように音量をそろえてある。

## 1_誤り事例_37件

発話が入っているか、文の内容どおりに読まれているかを聴く。判定は報告書の先頭にある1〜9の番号で書く。

## 2_アライメント_30件

音声に、アライメントが推定した各モーラの位置で短いクリック音（2kHz、12ms）を重ねてある。1モーラにつき1回鳴る。

判定の目安は次のとおり。
- 良好: クリックが音節の並びに合わせて鳴り、発話の始まりと終わりでも音声とずれない
- 部分的にずれる: 一部の区間（語末、息継ぎの前後など）で、クリックが先走る、遅れる、固まって鳴る
- 大きくずれる・失敗: 全体にクリックが音声と合わない、無音の区間でクリックが並ぶ

クリックの位置は、モーラの発音区間の中の1点である（多くは子音から母音に移る付近）。子音の立ち上がりと完全に一致しなくても、そのモーラの範囲内で鳴っていればずれではない。判断に迷う音声だけ、results/alignment_check/README.mdの手順でAudacityにラベルを読み込んで確認する。

## 3_無発話疑い_20件

自動判定（results/no_speech_detection.md の規則）で「発話が入っていない疑い」となったクリップのうち、聴取済みの37件（1_誤り事例_37件）以外から無作為に選んだ20件。判定が当たっているかを確かめるために聴く。報告書は「3_無発話疑い_報告書.md」から開ける。

判定は次の番号で書く。
1. 発話が聞き取れる
2. 発話がほぼ入っていない（雑音のみ・無音）
3. 一部だけ発話がある
4. 判断できない
