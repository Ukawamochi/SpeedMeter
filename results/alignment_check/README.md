# 強制アライメントの聴取確認（docs/directives/2026-09-25.md タスク4-2）

dev の強制アライメント（`docs/decisions/008-forced-alignment.md`、出力は `data/processed/alignments/dev.jsonl`）の境界を、人間が聴いて確認するためのファイル一式。
判定は `record.md` に記入する。タスク5-1は、30件中「大きくずれる・失敗」が3件を超えたら進まずに停止する。

## 抽出

- 配分: 4未満 7件、4以上6未満 8件、6以上8未満 8件、8以上 7件（30は4で割り切れないため端の2帯を1件ずつ減らした）

## ラベルの読み方（重要）

- CTC の出力はピーク状で、約9割のモーラの区間は1フレーム（20ms）しかない。**区間の長さはモーラの長さを表さない**。ラベルは「そのモーラがこの時刻付近にある」という位置の目印として見る
- したがって確認するのは、各ラベルの位置（特に開始時刻）が、そのかなが発音されている箇所の近くにあるか
- 1つのモーラは概ね 0.1〜0.2 秒。ラベルの位置が隣のモーラの発音位置まで外れていれば「1モーラ以上のずれ」
- 最初のラベルの開始が発話の開始、最後のラベルの終了が発話の終了に相当する。先頭・末尾の無音の中にラベルが入り込んでいないかも見る

## Audacity での確認手順

1. Audacity を起動し、「ファイル → 開く」で `<clip_id>.wav` を開く
2. 「ファイル → 取り込み → ラベル...」（英語版は File → Import → Labels...）で同じ名前の `<clip_id>.txt` を選ぶ。波形の下にラベルトラックが追加され、各モーラのかなが表示される
3. 表示を見やすくする: 「表示 → ズーム → 幅に合わせる」（英語版は View → Zoom → Fit to Width）の後、必要に応じて Ctrl（macOS は Cmd）＋1 で拡大する。ラベルが密集して読めない場合は拡大する
4. 境界を聴く:
   - 先頭から再生（スペースキー）し、再生位置の縦線がラベルを通過するときに、そのかなが聞こえているかを確かめる
   - 怪しい箇所は、ラベルトラック上でラベルをクリックすると該当区間が選択されるので、その前後を波形上でドラッグして選択し、再生して確かめる（1フレームのラベルは短すぎて単独では聞き取れないため、前後 0.1〜0.3 秒を含めて聴く）
   - 再生速度を落とす場合は「再生速度」ツールバー（「表示 → ツールバー → 再生速度ツールバー」）で 0.5 倍程度にする
5. 次の3点を見て判定する
   - 各ラベルが対応するかなの発音位置の近く（概ね1モーラ未満のずれ）にあるか
   - 最初・最後のラベルが発話の始まり・終わりに合っているか（無音や雑音の上に乗っていないか）
   - 途中の休止（息継ぎ）の中にラベルが並んでいないか
6. `record.md` の該当行に判定と備考を書く。判定は次の3つから選ぶ
   - **良好（境界のずれが概ね1モーラ未満）**
   - **部分的にずれる**（一部の区間で1モーラ以上ずれる。例: 語末や休止の前後だけずれる）
   - **大きくずれる・失敗**（全体に1モーラ以上ずれる、ラベルが無音上に並ぶ、発話の範囲が大きく外れる）
   - 備考には、ずれている箇所（時刻やかな）、原因の推測（雑音、読みの誤り、発音されない「ッ」など）を書く
7. 「ファイル → 閉じる」（保存しない）で閉じ、次のクリップへ進む。wav やラベルを編集・上書きしない
