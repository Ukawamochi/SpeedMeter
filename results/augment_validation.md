# 拡張設定の学習開始前検査

対象: `src/spkrate/data/augment.py`（`validate_augment_config`）と `src/spkrate/train/train.py`（`check_augment_setup`）。
`run_training` の冒頭、データ読み込みとモデル構築より前で `check_augment_setup` を呼ぶ。条件に当たると `AugmentSetupError`（`ValueError` の派生）を投げ、理由を log.txt に `拡張の設定の誤りで停止する: …` として書く。
参考: results/augmentation_check.md 3.2節。テスト: `tests/test_augment_validation.py`。

## 1. 学習開始前に停止させる条件（`augment.enabled: true` のときだけ検査する）

| # | 条件 | 停止しない場合に起きること |
| ---: | --- | --- |
| 1 | `augment.musan_root` が未設定 | 雑音源が `None` になり、雑音重畳が一度も行われない（augment.py `augment_waveform` の雑音の分岐）。警告も出ない |
| 2 | `musan_root` がディレクトリとして存在しない | データセット構築の段階で FileNotFoundError になる。これはモデル構築の後 |
| 3 | `musan_root/noise` が無い、または wav が0件 | 2と同じ |
| 4 | `data.source` が `features`（拡張ありなのに事前計算特徴量を使う設定） | 拡張は波形に掛かるので実行されない。これまでは `build_datasets` で止まっていたが、モデル構築の後だった |
| 5 | 確率 `*_prob` のいずれかが0（時間伸縮・残響・雑音重畳・帯域制限・音量変化・周波数マスク） | その拡張が一度も実行されない |
| 6 | 確率が0未満か1を超える、または有限でない | 設定の誤り |
| 7 | 範囲の下限が上限を超える、または有限でない値がある（範囲の項目すべて） | 最初のサンプルで `_uniform` が ValueError を投げる（学習の途中） |
| 8 | `time_stretch_range` が (1.0, 1.0) | 時間伸縮は常に無変化 |
| 9 | `time_stretch_range` の下限が0以下 | 伸縮率が0以下になり、学習の途中で ValueError |
| 10 | `librosa` を読み込めない | 最初の時間伸縮で ImportError（学習の途中） |
| 11 | `pyroomacoustics` または `scipy` を読み込めない | 最初の残響・帯域制限で ImportError（学習の途中） |
| 12 | `rt60_range` の下限が0以下 | 残響時間が0以下になる |
| 13 | 部屋の寸法の範囲の下限が1.0 m未満 | 音源とマイクの位置（壁から0.5 m）を引く範囲が空になり、学習の途中で ValueError |
| 14 | `reverb_max_order` が1未満 | 反射が計算されず、直接音だけの応答になる（残響は付かない） |
| 15 | 最小の部屋と最長の RT60 の組でも `pra.inverse_sabine` が失敗する | `generate_rir` が毎回無響の応答 `[1.0]` を返し、残響は一度も付かない |
| 16 | `low_hz_range` の上限が0以下で、かつ `high_hz_range` の下限がナイキスト周波数（8000 Hz）以上 | 帯域制限は常に無変化 |
| 17 | 低域遮断と高域遮断の範囲が重なる | 通過帯域が空になる組が引かれうる。引かれると学習の途中で ValueError |
| 18 | `band_limit_order` が1未満 | フィルタ設計の誤り |
| 19 | `gain_db_range` が (0.0, 0.0) | 音量変化は常に無変化 |
| 20 | `freq_mask_num` または `freq_mask_max_width` が0以下 | 周波数マスクは常に無変化 |
| 21 | `sample_rate` が16000でない | docs/spec.md の入力は16kHz。残響と帯域制限の周波数計算がずれる |

既定値（`AugmentConfig()`）と `musan_root: data/musan` の組み合わせはどの条件にも当たらない。実データでも確認し、雑音源は data/musan/noise の930ファイルだった。

## 2. 停止させないもの（サンプル単位で起きる正当なスキップ・変化）

| 箇所 | 事実 | 停止させない理由 |
| --- | --- | --- |
| `add_noise` | 信号の電力が1e-12以下（無音）なら雑音を足さない | 無音区間ではSN比が定義できない。サンプル単位の正当なスキップ |
| `add_noise` | 切り出した雑音の電力が1e-12以下なら足さない | 雑音ファイル側の無音区間。サンプル単位 |
| `change_volume` | `peak × gain > 0.99` のとき利得を `0.99 / peak` に抑える | クリップによる歪みを避けるため。正の利得が指定値より小さくなることがある |
| `generate_rir` | 引いた部屋の寸法と RT60 の組が実現できないと無響の応答 `[1.0]` を返す | 一部の組でだけ起きる。既定の範囲では残響を選んだ回の約3.9%（20,000回の抽選で測定、シード0）。最大の部屋（10×10×4 m）に RT60=0.1 秒を組み合わせると実現できない。どの組でも実現できない場合は条件15で止める |
| `generate_rir` | 応答のピークが1e-12以下なら `[1.0]` | 実際にはほぼ起きない |
| `band_limit` | 波形が24標本以下なら零位相フィルタを掛けない | 1.5ミリ秒以下の波形。実際のクリップでは起きない |
| `band_limit` | 引いた高域遮断がナイキスト周波数以上なら低域通過を省く。引いた低域遮断が0なら高域通過を省く | 範囲の一端でだけ起きる。既定の範囲では、低域遮断がちょうど0になる確率は0、高域遮断の上限は7800 Hz |
| `time_stretch` | 引いた伸縮率がちょうど1.0なら無変化 | 起きる確率は0 |
| `frequency_mask` | マスクの幅に0が引かれると、そのマスクは掛からない | 1本あたり1/13（既定の最大幅は12） |
| `build_datasets` | 検証セットには拡張を掛けない | 設計どおり（006の1節）。検証は常に features 経路 |
| `_build_noise_source` | 拡張ありで `musan_root` が無いと `None` を返す | `run_training` の中では条件1が先に止めるので、この分岐には到達しない。関数自体は変更していない |

なお `AugmentResult.applied` には、`add_noise` が無音で雑音を足さなかった回と、`generate_rir` が無響の応答を返した回も、それぞれ `noise`・`reverb` として記録される。

## 3. 実装せず docs/questions.md に記録したもの

- `augment.enabled: false` なのに `params` や `musan_root` が書かれている設定。いまは黙って無視される。止めるべきか判断できない
- 確率0で止める規則（条件5）と、第7段階で1種類の拡張だけを外すアブレーションとの両立。いまは確率0で必ず止まる
- 範囲が docs/spec.md の値（時間伸縮0.7〜1.5倍、SNR 0〜20 dB）の外に出る設定。無効化ではないので止めていない。仕様の範囲を強制するかどうかは判断できない
- 残響の既定の範囲では、残響を選んだ回の約3.9%が無響になる。範囲を変えるかどうか

## 4. log.txt の先頭の形式

`run_training` は学習ループより前に、次の順で書く。1行目にコミットと設定ファイル、続いて拡張の一覧。拡張が無効なら一覧の代わりに `拡張=なし` の1行を書く。
その後に、実験ID・デバイスの行、モデル、データの行が続く。

```
… INFO コミット=7d743c1… 設定=configs/expNNN.yaml
… INFO 拡張=あり 適用順=時間伸縮→残響→雑音重畳→帯域制限→音量変化（波形）→周波数マスク（特徴量）
… INFO 拡張: 時間伸縮 確率=0.5 伸縮率=0.7〜1.5倍
… INFO 拡張: 残響 確率=0.3 RT60=0.1〜0.7秒 部屋=3〜10×3〜10×2.3〜4m 最大反射次数=12
… INFO 拡張: 雑音重畳 確率=0.5 SNR=0〜20dB 雑音源=data/musan/noise（930ファイル）
… INFO 拡張: 帯域制限 確率=0.25 低域遮断=0〜300Hz 高域遮断=3400〜7800Hz 次数=4
… INFO 拡張: 音量変化 確率=0.5 利得=-12〜6dB
… INFO 拡張: 周波数マスク 確率=0.5 本数=2 最大幅=12メル 埋める値=0
```
