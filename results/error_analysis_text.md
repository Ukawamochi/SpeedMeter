## 1. 分類の方法

### 1.1 複数区分に当てはまる場合の扱い

**排他分類とし、優先順位を付けて先に該当した1区分にのみ計上する。** 合計は100件になる。
優先順位は次のとおりで、「正解ラベルそのものを疑う根拠があるか」→「入力の長さが極端か」→「正解値が希少か」→「残り」の順に置いた。

    A ラベル自体が誤っている　＞　D 原文に特殊な表記が含まれる　＞　B 極端に短いまたは長いクリップ　＞　C 毎秒モーラ数が分布の端にある　＞　E テキストからは原因が判断できない

排他分類だけでは重なりが見えなくなるため、**優先順位を無視した非排他の該当件数も 3 節に併記する**。

### 1.2 各区分の判定基準

| 区分 | 判定基準 | 基準の出所 |
| --- | --- | --- |
| **A** ラベル自体が誤っている（読み変換の誤り） | 原文とカタカナ読みを突き合わせ、pyopenjtalk の読みが原文の通常の読みと異なり、かつ**モーラ数が1以上ずれる**ことが原文だけから確認できる場合。読みが違ってもモーラ数が変わらない場合（例: 早川町 ハヤカワマチ / ハヤカワチョー、いずれも6モーラ）は該当させない | 目視判定。`spkrate.labels.mora.to_kana` で再現を確認 |
| **B** 極端に短いまたは長いクリップ | `duration_sec < 2.0 秒` または `duration_sec >= 9.4 秒` | dev 29,518件のクリップ長の第5パーセンタイル 1.98秒・第95パーセンタイル 9.396秒（`data/processed/clips.jsonl` と `configs/splits/dev.json` から算出）。下側の閾値 2.0秒は docs/spec.md の窓長と一致し、2.0秒未満は dev の 5.52%（`docs/experiments/003-first-model.md` 5.3節） |
| **C** 毎秒モーラ数が分布の端にある | `mora_per_second_true < 1.5` または `> 9.4` | `results/clip_filtering.md` 3節のヒストグラム（295,179件）の累積割合を線形補間した第1パーセンタイル 1.46・第99パーセンタイル 9.39 を丸めた値。dev 全件で直接算出すると 1.32・9.93 で同程度（dev で 9.4 超は 490件＝1.66%） |
| **D** 原文に特殊な表記が含まれる | NFKC正規化後の原文が次のいずれかに一致する。(d1) ラテン文字 `[A-Za-z]` を含む（全角ラテン文字は正規化でここに入る）、(d2) 同一文字の3回以上の連続 `(.)\1{2,}`、(d3) 3桁以上の数字列 `[0-9]{3,}`、(d4) 日本語の通常の句読点・括弧・中黒・長音記号以外の記号 | (d1)(d3) は docs/spec.md の前処理節と `src/spkrate/labels/filter.py` の除外条件に対応する。ただし**この除外は学習データ専用で dev には適用されない**ため、dev には残っている |
| **E** テキストからは原因が判断できない | A〜D のいずれにも該当しない | — |

## 4. 上位100件の偏りについて

6-1 の担当者の申し送りのとおり、`index.tsv` の上位100件には次の偏りがある。**この100件は dev の母集団を代表しない。**

| 項目 | 上位100件 | dev 全29,518件 |
| --- | ---: | ---: |
| 推定が過小（`signed_error < 0`） | 100件（100%） | — |
| 正解の帯 over8（8 mora/s 以上） | 75件（75%） | 2,015件（6.83%） |
| 正解の帯 6to8 | 25件（25%） | — |
| 正解の帯 under4・4to6 | **0件** | — |
| 毎秒モーラ数 9.4 超 | 52件（52%） | 490件（1.66%） |
| クリップ長 2.0秒未満 | 30件（30%） | 1,629件（5.52%） |

この偏りが分類の解釈に与える影響は次のとおりである。

1. **C（分布の端）の件数は、抽出方法によって構造的に押し上げられている。** 誤差 `|推定−正解|` の上位を取ると、正解値が大きい事例が自動的に集まる。dev で 9.4 超は 1.66% しかないのに上位100件では 52% を占める。したがって「C が52件（非排他）」は dev 全体で分布の端の事例が誤差の半分を作っているという意味ではなく、**誤差の上位だけを見ればそうなるという意味**である
2. **B（極端に短い）も同様である。** 2.0秒未満は dev の 5.52% だが上位100件では 30% である。ただし B と C の重なりは20件あり、短さ由来か速さ由来かは**この100件では分離できない**
3. **A・D の件数は過小評価である可能性が高い。** 読み変換の誤りや特殊表記は毎秒モーラ数を押し上げる向きにも押し下げる向きにも働くが、上位100件は全件が過小推定＝正解値が大きい側に偏っているため、**正解値を小さくする向きの読み変換の誤りはこの100件にほとんど入らない**。dev 全体での A・D の頻度はこの6件・6件からは推定できない
4. **under4・4to6 の帯の誤り事例が1件も入っていない。** `docs/experiments/003-first-model.md` 7節の申し送り2が懸念したとおりで、これら2帯（dev の大多数）の誤差要因は本分析の対象外である
5. **全件が過小推定であることは、5つの区分のどれとも独立に観測される。** 上位100件の推定毎秒モーラ数の中央値は 0.567、63件が 1.0 未満、49件が 0.5 未満である。`results/window_diagnostics.md` の D2 はデジタル無音の2.0秒窓に対する出力が 0.0824モーラ（＝0.041 mora/s）と記録している。上位100件の推定値はこの水準に近いものが多い。**ただしこれが音声側の何に由来するかはテキストからは判定できない**ため、区分の判定には使っていない

## 6. 本分析で判断できなかった点

- **原文と実際の発話が一致しているか**は判定できない。読み飛ばし・言い直し・途中切れがあれば正解モーラ数は音声に対して過大になるが、テキストだけでは区別できない。C に分類した25件と B に分類した30件の一部はこれに該当しうる
- **A（読み変換の誤り）の判定は目視である。** 難読語・固有名詞の正しい読みは原文からは確定できない場合があり（rank 30 の `身体`、rank 78 の `早川町` など）、`docs/experiments/001-mora-label-quality.md` 3節が述べるとおり Common Voice には人手の正解仮名が無いため検証できない
- **B と C を分離できていない。** B の30件のうち20件は C にも該当し、優先順位で B に入れている。どちらが誤差の主因かはこの100件からは決められない
- **A・D の dev 全体での頻度は不明である。** 4節の3に述べたとおり、上位100件は過小推定に全件偏っており頻度推定に使えない
