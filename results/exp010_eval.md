### 6.4 値の形（観察。解釈は A-4 に任せる）

- clean は、全体の MAE（0.4767）・8以上の MAE（0.6851）・8以上の偏り（−0.3789）とも基準の範囲の中か、その近く（s 未満）にある。エポック1の窓の16モーラ以上の割合の増え方（+1.5 ポイント）は小さい
- 雑音下では、全体の MAE（まとめ 0.6922、SNR 3条件とも）と 4〜6・6〜8 の帯の MAE が基準の範囲より小さい（6〜8 は s の 1.60倍）。一方で 8以上の過小（まとめ −0.7162）と全体の偏り（−0.0654）は基準の範囲より大きく負に出た。SNR 別の全体の偏りは 3条件とも −0.06〜−0.07 で、exp005・exp007（−0.05〜+0.01）より負に寄っている
- 雑音下の 8以上の偏りの形は exp008 と同じ向き（exp008 −0.7416、exp010 −0.7162）だが、exp010 は 8未満の帯の雑音下の MAE が小さく、全体の MAE が小さい点で exp008 と違う
- 正解0の窓は、clean・雑音下とも平均と割合が基準の範囲の中、99%点が悪い方の端のやや上（s 未満）にある。D2 の MUSAN noise（0.5067）は exp007 に近い
- G4 の 8以上（残り 0.0069）と G6 の 4〜6（残り 0.0039）は、基準は満たすが基準の上限に近い
