# 高速度域の評価（指示書 2026-09-28-fast-speech タスク1）

- 目的: 速い発話で出力が頭打ちになる問題について、正解の話速の区間別に出力が正解に追従しているかを測る。評価1は dev_window（clean・主指標）の区間別、評価2は速めた音声 dev_fast（WSOLA で1.5倍速・2倍速。作り方は results/dev_fast_build.md）の区間別
- 区間は窓の正解の毎秒モーラ数で、6未満（lt6）、1刻みの 6以上7未満（6to7）〜13以上14未満（13to14）、14以上（ge14）。偏り = 出力 − 正解 の平均。値はすべて主指標（dev_window と同じ除外の後）
- **本書は測定値と判定の基準だけを記録する。採否の判断はしない**（タスク3が docs/experiments/013-fast-speech.md で行う）
- configs/splits/test.json は使っていない。音声は聴いていない

## 1. 判定の基準（exp014・exp015 の結果が出る前、exp010 の値を見る前に固定した）

手順: exp005・exp007 の評価1・評価2を先に測り（3節）、その区間別の差を「区間別の偶然の揺れの目安」とした。基準はその値だけから決め、exp010 の集計はこの節をコミットした後に行った。exp014・exp015 はまだ学習していない。

### 1.1 区間別の揺れの目安 s_bin

exp005（mps で学習、種 20260921）と exp007（cuda で学習、種 20260929）の、同じ区間の出力の平均の差 |exp005 − exp007|（区間の正解の平均は2つで同じなので、偏りの差と等しい）:

| 区間 | 評価1 | 評価2 x1.5 | 評価2 x2 |
| --- | ---: | ---: | ---: |
| 6to7 | 0.014 | 0.011 | 0.007 |
| 7to8 | 0.031 | 0.001 | 0.013 |
| 8to9 | 0.050 | 0.015 | 0.014 |
| 9to10 | 0.066 | 0.021 | 0.031 |
| 10to11 | 0.085 | 0.030 | 0.031 |
| 11to12 | 0.093 | 0.050 | 0.032 |
| 12to13 | **0.107** | 0.065 | 0.045 |
| 13to14 | 0.058 | 0.047 | 0.055 |
| ge14 | 0.057 | 0.001 | 0.069 |

- **s_bin = 0.11 mora/s**。10以上の区間（10to11〜ge14）の3つの評価での最大 0.107 を切り上げた値を、すべての区間・評価に共通に使う（011-search-plan.md 2.1節と同じく、関連する指標では大きい方を共通に使う）
- 留意: 差は区間ごとに1つしかなく（2回の学習）、学習ごとの標準偏差の推定は粗い（results/run_variance.md 3節）。区間内の窓数による標本の揺れ（出力の標準偏差約1.3 ÷ √窓数。評価1の13to14で約0.03）はこれより小さい

### 1.2 基準の範囲

exp005 と exp007 の2つの値の範囲を「基準の範囲」とする（011-search-plan.md 2.1節と同じ）。

### 1.3 高速度域の基準（主な判定）

判定に使う6つのセル: {評価1, 評価2 x1.5, 評価2 x2} × {12to13, 13to14}。

| # | 名前 | 判定の仕方 | 基準の値（exp005・exp007 の範囲から） |
| --- | --- | --- | --- |
| F1 | 偏りの改善 | セルごとに、条件の \|偏り\| が基準の範囲の \|偏り\| の小さい方より s_bin 以上小さいとき「改善」、大きい方より s_bin 以上大きいとき「悪化」、それ以外は「差なし」。**6セルすべてが改善のとき F1 を満たす** | \|偏り\| の上限（改善とみなす値）: 評価1 12to13 ≤ 1.424、13to14 ≤ 2.199、x1.5 12to13 ≤ 1.148、13to14 ≤ 1.608、x2 12to13 ≤ 2.690、13to14 ≤ 2.941 |
| F2 | 追従（人間の目標「正解13〜14で出力が正解に追従する」） | セルごとに \|偏り\| ≤ T を「追従」とする。**T = 0.5 mora/s**。評価1の2セルがともに追従のとき F2 を満たす。評価2のセルの追従は、F2' と合わせて記録する | 基準では評価1 12to13 1.534〜1.640、13to14 2.309〜2.368（未達） |
| F2' | 評価2の相対の追従 | 評価2では、速めた音声そのものによる過小評価が通常の話速の区間にもある（基準の 6to7〜8to9 の偏り: x1.5 で −0.48〜−0.57、x2 で −1.24〜−1.85。3.2節）。そこで、同じモデル・同じ条件の 6to7・7to8・8to9 の偏りの平均を b_ref とし、相対の偏り = 偏り − b_ref とする。\|相対の偏り\| ≤ T のとき「相対の追従」とする。評価2の4セルは、絶対（F2 と同じ T）と相対の両方を記録する | 基準の相対の偏り: x1.5 12to13 −0.75〜−0.80、13to14 −1.21〜−1.25、x2 12to13 −1.27〜−1.30、13to14 −1.52〜−1.56（b_ref は x1.5 で −0.51〜−0.52、x2 で −1.53〜−1.55） |
| F3 | 単調な増加 | 評価ごとに、6to7 → 7to8 → … → 13to14 の隣り合う区間で、出力の平均の増分がすべて s_bin（0.11）以上のとき「単調」とする。**3つの評価すべてで単調のとき F3 を満たす**。13to14 → ge14 の増分は記録するが判定に使わない（ge14 は正解の幅が広く、評価1では窓数が少ない） | 基準は3つの評価とも単調（評価1の最小の増分は 12to13 → 13to14 の 0.22〜0.27）。13to14 → ge14 は評価1で −0.88（減少）、x1.5 で +0.53〜+0.58、x2 で +1.75〜+1.76 |
| F4 | 天井（記録） | 天井 = 評価ごとの区間の出力の平均の最大値（lt6〜ge14）。基準の範囲の上端より何 mora/s 上がったかを記録する。人間の目標の「2〜3 mora/s 上げる」に対応させ、**評価1の天井が 基準の上端 + 2.0 以上**になったかを記録する | 基準の天井: 評価1 10.916〜10.974（13to14）→ 目標の目安 ≥ 12.97。x1.5 12.116〜12.117（ge14）、x2 11.941〜12.010（ge14） |

- T = 0.5 の理由: 基準（exp005・exp007）の評価1で、\|偏り\| は 9to10 まで 0.26 以下、10to11 で 0.49〜0.58 に増える。指示書の背景の「10以上で過小評価が急に大きくなる」の境目の大きさであり、clean・主指標の全体の MAE（0.48）とも同程度である。この大きさ以下なら、13〜14 の窓が通常の話速域の上端（10前後）と同程度に扱えていると読む
- 境目の扱い（011-search-plan.md 2.1節と同じ）: F1 の改善・悪化が s_bin の1〜1.5倍の差で決まるセルは「境目」と注記する

### 1.4 通常の話速域の基準（守り）

dev_window（clean・主指標）の MAE と4つの帯別 MAE が、基準の範囲の悪い方の端から s（011-search-plan.md 2.1節）以上悪化しないこと。**条件の値 < 基準の悪い方の端 + s** のとき満たす。

| # | 指標 | exp005 | exp007 | s | 満たす条件 |
| --- | --- | ---: | ---: | ---: | --- |
| N1 | MAE 全体 | 0.4755 | 0.4786 | 0.005 | < 0.4836 |
| N2 | MAE 4未満 | 0.2893 | 0.2974 | 0.011 | < 0.3084 |
| N3 | MAE 4以上6未満 | 0.4572 | 0.4614 | 0.011 | < 0.4724 |
| N4 | MAE 6以上8未満 | 0.4692 | 0.4797 | 0.011 | < 0.4907 |
| N5 | MAE 8以上 | 0.6810 | 0.6714 | 0.011 | < 0.6920 |

N1〜N5 はすべて満たすことを求める。8以上の帯（N5）は高速度域の改善で下がりうるので、改善の向きの差も記録する。雑音下の精度はタスク3が既存の評価（dev_noisy・011 の基準）で見る。
