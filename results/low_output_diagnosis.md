# 低出力事例の切り分け（第6段階 追加診断）

- 生成: `PYTORCH_ENABLE_MPS_FALLBACK=1 uv run python scripts/low_output_diagnosis.py`（計算は `src/spkrate/eval/low_output_diag.py`）
- モデル: `runs/exp001/checkpoint_best.pt`（最良エポック 6）。デバイス `mps`
- 対象は dev のみ。`configs/splits/test.json` は使っていない。音声は聴いていない
- **本文書は数値と事実のみを記す。原因の推測・改善案は書かない**
- クリップごとの値: `results/low_output_diagnosis.tsv`

## 群の定義

- **対象群**: `results/error_cases/index.tsv` の 100 件のうち `mora_per_second_pred < 1.0` の件。**63 件**（想定の63件と一致）
- **比較群**: dev 全 29,518 件の予測（`runs/exp001/predictions_dev_full.json`）について毎秒モーラ数の絶対誤差を求め、その中央値 **0.3123 mora/s 以下**の 14,759 件（対象群を除く）から **63 件**を無作為抽出
  - 抽出: 候補を clip_id 順に並べ `np.random.default_rng(20260921).choice(候補数, size=63, replace=False)`。シード **20260921**

## 各値の算出方法

| 区分 | 算出方法 |
| --- | --- |
| 1 波形 | `spkrate.eval.audio.load_audio`（soundfile で読み、モノラル化、librosa で16kHzへ再標本化。学習・評価の特徴量計算と同じ読み込み）後の float32 波形。実効値 = sqrt(mean(x²))、ピーク = 振幅の絶対値の最大、無音標本の割合 = 振幅の絶対値が **0.001** 未満（-60dBFS）の標本の割合 |
| 2 形式 | 元ファイル: `soundfile.info` の samplerate・channels・frames/samplerate。読み込み後: `load_audio` の戻り値（16kHzモノラル）の標本化周波数・チャンネル数・長さ |
| 3 対数メル | 上の波形から `spkrate.features.melspec.log_mel_spectrogram`（docs/spec.md の設定。`scripts/precompute_features.py` と同じ関数）で計算し直した値の、全フレーム×80次元での統計 |
| 4 正規化後 | dev 評価の入力そのもの: `data/processed/features/dev` の float16 保存値を float32 に戻し、`configs/normalization.yaml`（mode=per_mel、80次元ごとの平均・標準偏差）で `(x-mean)/std` した値の統計 |
| 5 フレーム出力 | 4 の特徴量をクリップ全体のまま1件ずつ（詰め物なし、lengths=全フレーム数）`SpeechRateCNN.frame_counts` に与えた softplus 出力（モーラ/フレーム、1フレーム10ミリ秒）。dev 評価（`runs/exp001/eval_dev_full.py`）もクリップ全体を lengths 付きで与えており、詰め物は出力に影響しない。閾値は **0.01**（=1 mora/s 相当）と **0.05**（=5 mora/s 相当）|

入力の再現性の確認:

- 保存済み特徴量（float16）と計算し直した対数メルの差の絶対値の最大: 0.003906（全126件中の最大）
- `data/processed/clips.jsonl` の duration_sec（毎秒モーラ数の分母）と読み込み後の長さの差の絶対値の最大: 0.000e+00 秒
- 元ファイルの長さは `soundfile.info` の frames（mp3 のヘッダ・復号器が報告する値）から求めたもので、読み込み後（実際に復号した標本数から求めた長さ）とは一致しない場合がある
- フレーム出力の総和 ÷ クリップ長 と `runs/exp001/predictions_dev_full.json` の保存値の差の絶対値の最大: 1.020e-06 mora/s
- MPS の CPU フォールバック警告: **なし**
