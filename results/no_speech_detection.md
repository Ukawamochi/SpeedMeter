## 1. 指標（クリップごと）

| 指標 | 定義 |
| --- | --- |
| cer | アライメントと同じひらがなCTC（`vumichien/wav2vec2-large-xlsr-japanese-hiragana`、rev `017225bb128a6b1c6de9d58391f891908d69bc7b`、mps）の放出確率を、文を与えずに貪欲デコード（フレームごとの最尤トークン → 連続の重複をまとめ blank・区切り「\|」・[UNK] を除く）した結果と、正解のかなとの文字誤り率（レーベンシュタイン距離 ÷ 正解の文字数。1を超えうる） |
| 正解のかな | `clips.jsonl` の `kana`（カタカナ）を1文字ずつひらがなへ。語彙に無い「ゎゕゖゐゑ」はアライメントと同じく「わかけいえ」へ置き換え、それでも語彙に無い文字は捨てる。「ー」は語彙にあるので残す |
| hyp_len・hyp_mora_ratio | 認識結果の文字数、およびそれ ÷ ラベルのモーラ数 |
| ctc_nonblank_frac | 最尤トークンが blank・区切り以外のフレームの割合（CTC の発話区間の割合の目安） |
| ctc_nll_per_token | 正解の読みを与えたときの CTC 損失（負の対数尤度）÷ トークン数 |
| rms_dbfs・peak_dbfs | 全体の実効値、標本の絶対値の最大（dBFS） |
| frame_db_p10/p50/p90/p99 | 20ms フレーム（重なりなし）の実効値（dBFS）の分位点 |
| frame_db_range | フレーム実効値の95%点 − 10%点（dB。発話の有無による音量の起伏） |
| energy_speech_frac | フレーム実効値が10%点（雑音の床の目安）より15dB以上大きいフレームの割合（エネルギー基準の発話区間の割合） |
| abs_speech_frac | フレーム実効値が −45dBFS を超えるフレームの割合 |

- 処理時間は29,518件で2,920秒（0.099秒/件、読み込み込み）。失敗0件。**警告は0件で、MPS の CPU フォールバックは起きなかった**（警告は clip_id つきでログに記録する実装）
- CTC モデルは Common Voice 日本語で微調整されており、dev のクリップが学習に含まれていた可能性がある（未確認）。その場合、認識結果が文の記憶に引きずられ、cer が実際の音声より低く出ることがありうる

## 4. 採用した規則

**no_speech_suspect ⇔ frame_db_p90 <= −25.5 dBFS かつ frame_db_range <= 33.3 dB かつ cer >= 0.4**（`configs/eval/no_speech.yaml`）

- 37件をすべて検出する（見逃し0）。37件以外の該当は382件（上限の見積もり）
- 選んだ理由: 1指標の最良（frame_db_range、1,741件）・2指標の最良（frame_db_p90 と frame_db_range、512件）より該当が少なく、3指標の中で最少。4指標にしても減りは91件で、加わる条件（hyp_mora_ratio <= 1.21）は1件の外れ値に合わせた緩い閾値のため採らなかった。音量の条件2つは「小さく起伏の乏しい音」、cer は「認識で文が再現されない」を表し、互いに独立な観点である
- 閾値の根拠はいずれも37件の端の1〜数件（2節）であり、境界付近の値は37件という少数に強く依存する。特に cer の閾値0.4は#21の1件で決まっており、#21を除けば0.84になる（3節の参考）
- 382件のうち認識結果が空のもの45件、cer >= 0.9 のもの193件、rms <= −50dBFS のもの72件（37件ではそれぞれ14件・33件・21件）。382件には、小さい・起伏の乏しい録音で認識を誤っただけの発話入りのクリップも含まれうる

## 7. 既知の限界と未解決点

- 規則は37件という少数の正例だけに合わせたもので、正例の偏り（高速帯・短いクリップ・6-1 の誤り上位からの選抜）を受けている。37件と違う性質の無発話クリップ（例: 大きな雑音の中に起伏がある）は見逃しうる
- 「37件以外の該当382件」は誤検出の上限であり、真の誤検出率は聴取（6節の20件）でしか見積もれない
- #21 は認識が文をかなり再現しており、無発話とする聴取判定と CTC の結果が食い違う。cer の閾値はこの1件で0.4まで下がっている
- CTC モデルの学習データに dev のクリップが含まれていた場合、cer は低めに出る。含まれるかは確認していない
- train への適用はしていない（指示どおり）
