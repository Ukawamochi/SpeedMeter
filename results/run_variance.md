留意点:

- **2回の学習だけでは揺れの推定は粗い。**各指標について差は1つ（自由度1）しかない。学習ごとの標準偏差を \|差\|/√2 と見積もると、その95%信頼区間はおおよそ 0.45倍〜32倍の幅になる（カイ二乗分布の自由度1による）。上の表は1回の観測値で、真の揺れはこれより大きいことも小さいこともある。値そのものより、指標ごとの大きさの順序（全体の MAE は小さく、帯・偏り・正解0の出力・D2 は大きい）を参考にするのがよい
- 全体の MAE は揺れが小さい（0.001〜0.003）が、帯別の値・偏り・正解0の窓の出力（とくに裾と雑音下）・D2 は、同じ設定でも全体の MAE の数倍〜数十倍動く。窓ごとの予測は2つのモデルで平均 0.2〜0.33 毎秒モーラ違う（2.4節）
- 最良エポックの選び方の揺れ（エポック間の検証 MAE の差が 0.01 前後）も含まれる。exp005 と exp007 は、最良エポック（26 と 27）が近く、どちらも上限30エポックで終わった
- 種の差と学習の計算機の差を分けるには、同じ計算機で種だけを変えた学習（または同じ種で計算機だけを変えた学習）が要る。本書では行っていない
- 以後の条件を ubuntu-desktop（cuda）で学習する場合、基準の exp005（mps）との比較には計算機の差も含まれる。exp007（cuda）とも並べると、同じ計算機での比較が1つ得られる
