# 話者単位の分割（train / dev / test）

- 入力: `data/processed/clips.jsonl`（2-2 のクリップ一覧）
- 出力: `configs/splits/train.json`, `dev.json`, `test.json`
- 生成スクリプト: `scripts/build_splits.py`
- 実装: `src/spkrate/data/splits.py`（`assign_speakers`）
- 乱数シード: **20260921**（固定。同じ入力なら常に同じ分割になる）
- 対象: 話者 6,889 人、クリップ 295,179 件

**禁止事項: configs/splits/test.json は docs/PLAN.md 第10段階（最終評価）まで使用禁止。条件の選択・途中の評価には dev.json のみを使う。**

## 1. 分割方法

- 分割の単位は `client_id`。同一話者が複数の分割に現れることはない
- 比率 8:1:1 は**クリップ数**で合わせる（話者ごとのクリップ数の偏りが大きいため、話者数の比率では合わせない）
- 手順（貪欲法）
    1. 話者を `client_id` の昇順に整列する（入力の並び順に依存させない）
    2. `random.Random(20260921)` でシャッフルする
    3. クリップ数の多い順に安定ソートする
    4. 先頭から、目標クリップ数に対する不足が最大の分割へ割り当てる（同点なら train, dev, test の順）

## 2. json の形式

各ファイルは次のキーを持つ1つのオブジェクトである。

| キー | 内容 |
| --- | --- |
| `split` | 分割名（train / dev / test） |
| `unit` | 分割の単位。常に `client_id` |
| `seed` | 生成に使った乱数シード |
| `method` | 割り当て方法 |
| `target_ratio` | 目標のクリップ数比率 |
| `source` | 元にしたクリップ一覧のパス |
| `generated_by` / `implementation` | 生成スクリプトと実装のパス |
| `num_speakers` / `num_clips` / `total_duration_sec` | 実際の規模 |
| `usage_restriction` | test.json のみ。使用禁止の注記 |
| `client_ids` | **分割に含まれる client_id の一覧（昇順）** |

読み出しは `spkrate.data.splits.load_split`（train / dev）を使う。test.json は `load_test_split` 専用で、`stage10_approved=True` を明示しない限り例外になる。

## 3. 各分割の規模

| 分割 | 話者数 | クリップ数 | クリップ数の割合(%) | 合計時間(時間) |
| --- | ---: | ---: | ---: | ---: |
| train | 3,467 | 236,143 | 80.00 | 304.80 |
| dev | 1,711 | 29,518 | 10.00 | 37.10 |
| test | 1,711 | 29,518 | 10.00 | 37.76 |
| 合計 | 6,889 | 295,179 | 100.00 | 379.67 |

目標比率は train 80.00 / dev 10.00 / test 10.00 パーセントである。

## 4. 毎秒モーラ数の分布

| 分割 | 最小 | 第1四分位 | 中央値 | 平均 | 第3四分位 | 最大 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 1.001 | 3.868 | 4.994 | 5.040 | 6.129 | 12.000 |
| dev | 1.004 | 3.584 | 4.854 | 5.003 | 6.301 | 11.983 |
| test | 1.001 | 3.608 | 4.856 | 4.986 | 6.272 | 11.979 |

外れ値（1未満・12超）は 2-2 の段階で除外済みのため、最小・最大はその範囲に収まる。

## 5. 重複の検証

同一話者が複数の分割に現れないことは `tests/test_splits.py` で検証する。生成済みの json を読む検証と、合成データで分割関数の性質（話者単位であること・決定的であること）を確かめる検証の両方を持つ。
