- 実施: 第6段階の測定サブエージェント（第4段階4-3が第5段階5-4に課した診断。5-4では前向き計算ができず未測定だった）
- 生成: `uv run python scripts/window_diagnostics.py`（計算の骨格は `src/spkrate/eval/window_diag.py`）
- モデル: `runs/exp001/checkpoint_best.pt`（実験ID `005-first-model`、最良エポック 6、受容野 69 フレーム）

- **本文書は測定値と閾値超過の有無だけを記録する。結果の解釈・採否の判断は書かない**（第7段階7-1の仕事）

## D1 分割整合性

先頭から重なりなしに2.0秒窓を m = floor(T/2.0) 個とり、各窓を単独で推論した値の総和 Σ と、
同じ 2.0m 秒の区間を一括で推論した値 P を比べる。診断値は `|Σ − P| / (2.0m)`（mora/s）。

| 項目 | 値 |
| --- | ---: |
| 母集団（dev の4.0秒以上） | 13,322 件 |
| 標本 | 1,000 件（無作為） |
| 1件あたりの窓数（平均） | 2.850 |
| 1件あたりの対象区間長（平均） | 5.700 秒 |
| Σ の平均 | 33.3204 モーラ |
| P の平均 | 35.9307 モーラ |
| **D1 = mean(\|Σ − P\|/(2.0m))** | **0.4360 mora/s** |
| 中央値 | 0.4019 mora/s |
| 第9十分位 | 0.7830 mora/s |
| 最大 | 1.6505 mora/s |
| 標準偏差 | 0.2705 mora/s |
| 符号つき (Σ − P)/(2.0m) の平均 | -0.4333 mora/s |

- 閾値 **B1: D1 > 0.25 mora/s** に対して **超過**（測定値 0.4360 vs 閾値 0.25）

## D2 無音・雑音窓の出力

デジタル無音の2.0秒窓と MUSAN noise のみの2.0秒窓を推論する。仕様は「無音は0モーラ」。

| 入力 | 本数 | 平均（モーラ） | 中央値 | 最大 | 標準偏差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| デジタル無音 | 500 | **0.0824** | 0.0824 | 0.0824 | 0.0000 |
| MUSAN noise | 500 | **4.7024** | 4.1652 | 21.4650 | 3.7183 |

MUSAN noise の窓は元ファイルの振幅のままで、音量を合わせる操作はしていない（005 は D2 の音量を指定していない）。
実効値は平均 0.12490、中央値 0.08532、最大 0.84088。

**参考（005の定義には無い追加測定）**: 同じ500本を dev 音声の実効値の中央値 0.05749 に
揃え直して推論すると、平均 4.6909 モーラ（中央値 3.9418、最大 24.9051）。

閾値 **B2: D2 > 1.0 モーラ** に対して:

- デジタル無音 0.0824 モーラ → **超過しない**
- MUSAN noise 4.7024 モーラ → **超過**
- 2種のうち大きい方 4.7024 モーラ → **超過**

## D3 連結加法性

dev から2件ずつ組にして 0.2秒の無音を挟んで連結し、`P(AB)` と `P(A)+P(B)+P(無音)` を比べる。
診断値は `|差| / 連結後の長さ`（mora/s）。

| 項目 | 値 |
| --- | ---: |
| 組数 | 500 組（母集団は dev 全件） |
| 連結後の長さ（平均） | 9.352 秒 |
| P(無音 0.2秒) の平均 | 0.0001 モーラ |
| 差 `P(AB) − (P(A)+P(B)+P(無音))` の平均（符号つき） | +0.4437 モーラ |
| \|差\| の平均 | 0.4664 モーラ |
| **D3 = mean(\|差\|/連結後の長さ)** | **0.0568 mora/s** |
| 中央値 | 0.0297 mora/s |
| 第9十分位 | 0.1447 mora/s |
| 最大 | 0.4425 mora/s |

- 閾値 **B5: D3 > 0.25 mora/s**（D1 との併発時のみ）に対して、D3 単独では **超過しない**（測定値 0.0568）。D1 との併発を含めた B5 の成立は **該当しない**

---

## 閾値に対する超過の有無（まとめ）

| 条件 | 閾値 | 測定値 | 超過 |
| --- | ---: | ---: | --- |
| B1 | D1 > 0.25 mora/s | D1=0.4360 | **超過** |
| B2（デジタル無音） | D2 > 1.0 モーラ | 0.0824 | **超過しない** |
| B2（MUSAN noise） | D2 > 1.0 モーラ | 4.7024 | **超過** |
| B5 | D3 > 0.25 mora/s かつ B1 成立 | D3=0.0568 / B1=成立 | **該当しない** |

採否の判断は行わない（第7段階7-1）。
